# Wishly — exemple de liste de cadeaux

> **Projet de démonstration uniquement.** Tous les noms, cadeaux, descriptions et prix affichés sont fictifs.

Wishly est ici une petite maquette HTML/CSS/JavaScript pour illustrer une interface de liste de cadeaux. Elle n'est pas une version de production.

## Lancer la démo

Ouvre simplement `index.html` dans un navigateur. Aucune installation, aucun compte et aucun serveur ne sont nécessaires.

## Ce que la démo montre

- Une liste de cadeaux avec noms et données inventés
- Recherche et filtre par catégorie
- Compteurs d'idées disponibles et réservées
- Boutons de réservation de démonstration
- Mise en page adaptée aux écrans mobiles et ordinateurs

## Limites importantes

- Aucune authentification n'est implémentée.
- Aucune donnée n'est envoyée à un serveur.
- Les réservations sont stockées uniquement dans le stockage local du navigateur.
- Aucun paiement ni lien d'achat réel n'est utilisé.
- Il n'y a aucune connexion Supabase, base de données distante, administration réelle ou protection de production.
- Cette maquette ne doit pas être utilisée pour recueillir de vraies informations personnelles.

## Personnages fictifs

- **Camille Martin** : personne qui crée la liste.
- **Alex Dupont** : visiteur fictif.
- Les articles, prix et événements sont inventés pour la démonstration.

## Structure

- `index.html` : application de démonstration autonome.
- `README.md` : documentation de la maquette.
- `SECURITY.md` : limites et règles de sécurité du projet de démonstration.

## Pour une vraie application

Avant de transformer cette maquette en service réel, il faudrait concevoir et tester séparément l'authentification, les autorisations côté serveur, la protection des données, les politiques de base de données, les sauvegardes, la modération et les procédures de suppression. Cette maquette ne fournit pas ces garanties.
