# Wishly — démo interactive

**Projet de démonstration uniquement.** Tous les noms, listes, cadeaux, descriptions et prix sont fictifs.

Site : https://ethangalea1000-svg.github.io/Wishly/

## Fonctions de la maquette
- Interface responsive.
- Recherche et filtres par catégorie.
- Réservations simulées dans la page.
- Ajout local d'idées fictives.
- Formulaire de création d'une liste exemple.

## Limites
Ce projet est une maquette HTML/CSS/JavaScript. Il n'y a pas de compte réel, de base de données, de synchronisation, de paiement, de réservation partagée ni d'import réel depuis des boutiques. Les modifications servent uniquement à essayer l'interface.

## Lancer localement
Ouvrir `index.html` dans un navigateur récent. Aucune installation n'est nécessaire.

Le dépôt est public : ne pas y placer de secret ni de donnée personnelle. Le dépôt source `Liste-cadeaux-ethan` reste séparé et n'est pas modifié par ce projet.
