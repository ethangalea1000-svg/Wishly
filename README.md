**Démo uniquement.** Cette version reprend l'interface de la liste de cadeaux d'origine à titre d'exemple. Le nom affiché a été remplacé par un nom fictif et les connexions à la base distante sont désactivées. Aucun compte, partage réel, réservation synchronisée ni paiement ne doit être considéré comme opérationnel.

Site : https://ethangalea1000-svg.github.io/Wishly/

## Important
- Le dépôt original `Liste-cadeaux-ethan` n'a pas été modifié.
- Le code ici est une copie séparée destinée à une démonstration.
- Les appels au backend Supabase sont désactivés dans cette copie ; aucune clé réelle de connexion n'est conservée.
- N'utilisez pas cette version pour des listes réelles ou des informations personnelles.
- Le dépôt est public : ne publiez aucun secret ni aucune donnée privée.

Pour essayer localement, ouvrez `index.html` dans un navigateur récent. GitHub Pages doit être activé sur la branche `main`, dossier `/(root)`, pour publier le site.
