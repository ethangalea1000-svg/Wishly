# Sécurité — Wishly Demo

Cette branche du projet est une maquette publique et non une application de production.

- Utiliser uniquement les données fictives fournies dans la démo.
- Ne pas ajouter de noms, e-mails, codes d'accès, photos ou autres données personnelles réelles.
- Ne pas ajouter de clé privée, de jeton ou de secret dans le code.
- Aucune base de données distante ni authentification n'est configurée.
- Le stockage local n'est pas un mécanisme de sécurité et peut être effacé depuis le navigateur.
- Les interactions de réservation servent uniquement à illustrer l'interface.
- Avant tout usage réel, une revue de sécurité et de confidentialité complète est nécessaire.

**Important :** remplacer les fichiers actuels par ces fichiers ne supprime pas automatiquement les anciennes versions de l'historique Git. Des commits antérieurs peuvent encore contenir l'ancien code.
